LocalAI Mobile — Reskinning & Customization Guide

Complete documentation for branding, configuring, reskinning, and deploying the LocalAI Mobile starter kit for Android and iOS.

1. Quickstart & Development Setup

System Prerequisites: Node.js (18+ / 20+ / 22+ LTS), Android Studio & JDK 17 (for Android), macOS & Xcode 15+ (for iOS).

# 1. Install dependencies
npm install

# 2. Run automated verification (verifies types and tests)
npm run typecheck
npm test

# 3. Launch on physical device or emulator
npm run android   # Generates native android/ via Expo prebuild
npm run ios       # Generates native ios/ via Expo prebuild
Important: Because LocalAI Mobile uses native C++ bindings (llama.rn) and native ML Kit modules, it must be run as a native development build (npm run android / npm run ios) rather than standard Expo Go.

2. App Identity: Name, App ID & Package Name

All high-level app identifiers are configured in app.json located at the root of the project.

Changing App Display Name & Slug

Open app.json and update the top-level fields:

{
  "expo": {
    "name": "MyBrand AI",          // <-- Your App's public display name (under phone icon)
    "slug": "mybrand-ai",          // <-- URL-safe project slug
    "scheme": "mybrand",           // <-- Custom URL scheme (e.g., mybrand://chat)
    "version": "1.0.0"             // <-- Your app release version
  }
}

Changing the Android Package Name (Application ID)

In app.json, navigate to the expo.android block:

{
  "expo": {
    "android": {
      "package": "com.mycompany.mybrandai"  // <-- Replace with your unique Android package name
    }
  }
}

Changing the iOS Bundle Identifier

In app.json, navigate to the expo.ios block:

{
  "expo": {
    "ios": {
      "bundleIdentifier": "com.mycompany.mybrandai"  // <-- Replace with your unique iOS bundle identifier
    }
  }
}

3. App Icons & Splash Screen

All image assets are stored inside the assets/ directory.

Asset File Resolution Format Purpose
assets/icon.png 1024 × 1024 px PNG App Store & Google Play Icon
assets/adaptive-icon.png 1024 × 1024 px Transparent PNG Android Adaptive Foreground Icon
assets/splash.png 1284 × 2778 px PNG Launch / Splash Screen Image

To update the background color of your splash screen and adaptive icon, edit app.json:

{
  "expo": {
    "backgroundColor": "#0A0A0C",
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#0A0A0C"
    },
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#0A0A0C"
      }
    }
  }
}

After updating icons, regenerate the native assets with: npx expo prebuild --clean

4. Color Palettes, Themes & Visual Styling

The app includes an intelligent color engine that derives harmonic, high-contrast UI palettes from a seed color or user-selected wallpapers.

Changing the Default Theme Seed

Open src/core/appearancePalette.ts at line 17:

export const DEFAULT_SEED = '#6366F1'; // Set your brand primary hex color

Overriding UI Colors

In src/core/appearancePalette.ts, modify the createTheme function:

colors: {
  background: '#0B0F19',          // <-- Main screen background
  surface: '#111827',             // <-- Chat cards, drawer & dialog surfaces
  surfaceHighlight: '#1F2937',    // <-- Hover/active states
  surfaceBorder: '#374151',       // <-- Subtle borders
  accent: '#6366F1',              // <-- Primary buttons & badges
  text: '#F9FAFB',                // <-- Primary text color (high contrast)
  textSecondary: '#D1D5DB',       // <-- Secondary text
  textMuted: '#9CA3AF'            // <-- Placeholders & timestamps
}

5. Interface Strings & App Text Customization

  • Header Brand Name: Open src/components/Header.tsx (line 12) and change brand="Qwerty" to brand="MyBrand".
  • Empty State Title & Subtitle: Open app/index.tsx (lines 371-374) to modify the welcome greeting and tagline.
  • Chat Input Placeholder: Open src/components/Composer.tsx (line 275) to customize the composer placeholder string.
  • Chat Export Filename: Open app/index.tsx (line 348) to change the export session prefix.

6. AI Personas & System Prompts

Open src/constants/models.ts and find PERSONA_PRESETS (lines 120-163). You can modify persona labels, icons, and prompts, or append your own custom domain personas.

export const PERSONA_PRESETS: PersonaPreset[] = [
  {
    id: 'companion',
    label: 'Everyday Companion',
    icon: '🧠',
    shortDesc: 'Friendly, concise, helpful conversational assistant',
    prompt: 'You are MyBrand, a friendly on-device conversational assistant...'
  },
  // Add custom personas here!
];

7. Curated Models & Inference Defaults

In src/constants/models.ts, the CURATED_MODELS array specifies the download links, metadata, and default context lengths for local GGUF models. You can add any GGUF model compatible with llama.cpp.

Default inference settings (context window, thread count, temperature) are configured under DEFAULT_INFERENCE_CONFIG in the same file.

8. Production Builds & Store Publishing

Cloud Builds with EAS Build (Recommended)

# Install EAS CLI
npm install -g eas-cli

# Login and build signed production release
eas login
eas build --platform android --profile production
eas build --platform ios --profile production

Local Android Gradle Build

# Build signed Android App Bundle (.aab) locally
cd android
./gradlew bundleRelease

The compiled bundle will be available at android/app/build/outputs/bundle/release/app-release.aab, ready for submission to the Google Play Console.
